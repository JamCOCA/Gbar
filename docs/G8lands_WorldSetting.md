## 〇、整合总览

本文档将两部分合为一体：

1. **世界观**：《G8lands》伪科幻魔法体系（催化魔法 / CPC / 血蓝同池）
2. **玩法框架**：机制层最简骨架（永久死亡、衰减流通、动态平衡、周期轮回）

整合逻辑一句话：**CPC 的"活性"就是这个世界的石油——它有限、会失活、只能在活体神经中缓慢合成。所有反常规机制都是这一物质的物理性质的自然推论。**

### 四根承重柱的世界观落点

| 承重柱 | 世界观解释 |
|---|---|
| 永久改变（怪物死不刷新） | 怪物是被活性 CPC 深度侵染的敏化人，死亡后体内 CPC 消旋失活；每个区域的逃逸个体数量有限，杀完即绝 |

## 一、世界核心公理：热力学与动力学魔法论

近未来的生物科技突破中，人类在人体神经系统中发现并解析了一种微观纳米级特化物质。该体系重构了对"超自然/魔法"的认知：**魔法不是违背物理规律的虚空造物，而是对"化学与物理反应动力学能垒"的绝对掌控。**

* **公理一（动力学控制·能垒清零）**：施法者通过释放神经催化介质，可将目标空间内指定反应的**活化能（Ea）瞬间降为零**。
* **公理二（热力学铁律·能量守恒）**：催化剂只能抹平反应阻碍，**不能无中生有创造能量**。反应能否自发进行仍受吉布斯自由能（ΔG）制约。
* **公理三（生物合成·不可工业化）**：活性 CPC 只能在活体神经胶质细胞中合成，速率缓慢，且合成过程对神经系统造成不可逆负荷。**无法工业化量产，无法人工替代**——这是全世界经济系统的地基。
* **公理四（手性消旋·活性衰减）**：CPC 的催化活性等于其手性纯度。离体后的 CPC 随时间发生不可逆消旋，活性持续下降直至归零。**囤积即贬值**是物理法则，不是游戏规则。

## 二、能量与资源流转机制（血蓝同池系统）

本世界观严格区分两类反应，并由此构建独特的战斗资源与施法代价系统：

### 1. 自发/放热反应（ΔG < 0，毁灭系 / 元素系）
* **代表现象**：常温自燃、爆轰冲击波、分子键自发断裂、空气电离。
* **能量来源**：环境物质本身的化学势能（如空气中的氧气与还原性尘埃/燃料）。
* **施法消耗**：主要消耗**神经催化介质（蓝条）**，用于构建、维持和约束催化场。
* **施法限制**：受环境介质制约（真空、缺氧或无燃料环境中威力锐减）。

### 2. 非自发/吸热/熵减反应（ΔG > 0，构造型 / 治疗系）
* **代表现象**：伤口组织肉芽快速增殖（治疗）、物质重构/硬化（造物、石墙、护盾）、复杂分子合成。
* **能量来源**：**必须引入外部"供能偶联反应"**。施法者必须以自身血液/肉体高能物质（或外置高能燃料）作为牺牲反应源。
* **施法消耗**：**生命值（血条）与催化介质（蓝条）双重消耗**。
  * 施法者割裂皮肤，催化血液中的血红蛋白、糖原与高能磷酸键剧烈氧化分解，以释放的自由能作为"生物能量泵"强行驱动熵减反应。

## 三、生物学载体与微观结构

### 1. 介质本质：手性极化微团（Chiral Polariton Clusters, CPC）
* **分子结构**：由特化手性多肽包裹铁-钼-钨杂核过渡金属中心构成的纳米级超分子胶体。
* **物理机制**：被生物高频电脉冲激活后，展现常温量子相干效应，与反应物分子电子云形成共振隧穿，在势能面上"凿穿"能垒。
* **体内安全机制**：在体内以"酶原"形式高度折叠并络合抗活性蛋白，处于完全钝化态，防止自身组织被溶解自燃。

### 2. 神经解剖与释放途径
* **合成源**：脑内变异神经胶质细胞的特化细胞器（能垒折叠体）。
* **储存与外泌**：
  * **手势/结印（掌指分泌）**：掌心与指尖密集的外周神经末梢与特化微腺体共管，随汗液/微气溶胶喷出。
  * **咏唱/言灵（声带雾化）**：迷走神经调控声带高频超声振动，将气道黏膜分泌的 CPC 原液超细雾化，随呼吸精准喷吐。
  * **近战附魔（接触渗透）**：通过皮肤直接接触将介质注入武器或目标表面。
* **定向投射（生物电离子风）**：外周神经在喷射瞬间释放数千伏特的高频微电流脉冲，极化纳米微团，顺着空气电离通道高速飞向目标。

## 四、施法代价、病理表现与战术克制

### 1. 资源条与负荷机制
* **催化介质储量（蓝条）**：神经系统内可立即动用的有效递质浓度，决定施法频率与维持时长。
* **生命健康度（血条）**：肉体组织与循环系统储备，承受敌方伤害与自残施法的共同血池。
* **透支临床表现（施法副作用，直接作为 debuff 梯度）**：
  * **轻度**：末梢神经麻木、手指颤抖、触觉丧失 → 操作精度下降。
  * **中度**：舌肌僵硬（无法咏唱）、视野模糊、偏头痛、低血糖虚脱 → 封锁咏唱系技能。
  * **重度/枯竭**：全身神经突触受损、重症肌无力、急性高渗性脱水或植物人昏迷 → 角色瘫痪。

### 2. 战术装备与现代衍生
* **神经传导法杖/枪械**：内部铺设超导神经纤维与碳纳米管，将人体外周神经延长，利用尖端放电效应提升射程与聚焦精度。
* **外置供能血包/ATP 燃料棒**：挂载于腰间的高浓度生物燃料，替代自身放血供能。**工业血包 = 敏化人血液提取物；顶级血包 = 活体链接的圈养敏化人**（见第六章）。
* **战救神经补充剂（蓝药）**：高浓度递质前体 + 神经节苷脂 + 营养因子的静脉快速注射针。
* **反制战术（法术沉默）**：
  * **化学失活**：喷洒强酸/蛋白酶气雾剂使空气中的 CPC 变性失效。
  * **流场干扰**：大功率排风装置或气压弹直接吹散催化气溶胶。

## 五、敏化人：这个世界的"怪物"

### 1. 起源

CPC 由神经合成，**神经越敏感，产量越高**。早期财团与政府为此制造了第一代神经改造人——通过基因编辑与神经扩容手术，将人类的感知灵敏度推到生理极限，作为**活体 CPC 工厂**圈养。

代价是绝对的：过度敏感的神经系统无法承受日光——紫外线与强光对其而言是持续的伤害性刺激。**敏感度越高，畏光越甚，居所越深。**

### 2. 现状

某次事故（或暴动，细节待定）后，改造人摆脱掌控，大规模迁入地下。经过数代繁衍，他们在地底建立了自己的社会：有语言、有工具、有分工、有对地表人的记忆与仇恨。

**他们不再是产品。他们是另一个文明。**

### 3. 层级体系（对应玩法的难度梯度）

| 层级 | 个体 | 玩法定位 |
|---|---|---|
| 地表游荡者 | 逃逸的弱个体、表型崩溃的退化者，畏光但可耐受微弱日光 | 地表怪物，**数量有限、死亡不刷新** |
| 浅层（地下一层） | 低敏化个体，产量低、战斗力弱 | **新人单人安全成长线** |
| 中层 | 标准敏化人，有社会组织、会使用工具与战术 | 组队内容 |
| 深层 | 高敏化个体，CPC 产量惊人，感知强到近乎预知 | 精英团队内容 |
| 最深处 | **零号实验体**——第一个改造人，一切敏化人的源头 | **位面 BOSS**，全服合力讨伐 |

### 4. 智能行为（AI 设计依据）

敏化人是人。他们的"智能行为树"不需要任何科幻包装：

* 会分析战场局势，优先攻击高威胁目标（施法者、治疗者）
* 会埋伏、会撤退、会谈判、会记仇
* 可被环境与玩家行为诱导（声东击西、诱饵、断粮）
* 有社会组织：巡逻队、伏击组、护送队、复仇队

### 5. 夜袭劫掠（对应原"虫潮"全服防守事件）

地下资源不全——食物、药品、某些材料只能来自地表。敏化人周期性组织夜袭，劫掠地表设施与圈养场（他们称之为"解放"）。

* 周期性触发，全服防守
* 防守成功：全服奖励
* 防守失败：公共设施与圈养场受损，需重建；被圈养的敏化人会被劫走

## 六、玩家立场与捕获/圈养系统

### 1. 玩家是谁

玩家是**正统人类**——未接受敏化改造（或仅接受安全范围内的民用改造）的地表人。在这个世界，CPC 是施法、装备、能源的共同基础，而敏化人是已知最高效的 CPC 来源。

**在这个世界，最值钱的矿脉长在人身上。**

### 2. 对敏化人的三种处置

| 处置 | 收益 | 性质 |
|---|---|---|
| **击杀** | 一次性回收含 CPC 的生物质材料（催化腺体、神经组织、富集血液） | 原有掉落逻辑 |
| **捕获圈养** | 遮光圈养场中持续产出 CPC（农场玩法，长期收益） | 新增核心经营玩法 |
| **活体血包** | 高阶个体活体链接，作为随身外置供能源（顶级装备） | 装备系统的黑暗顶点 |

### 3. 圈养场玩法闭环

> 攻坚清空区域 → 安全区开放建设 → 建遮光圈养场 → 投放捕获的敏化人 → 持续产出 CPC → 圈养场吸引夜袭 → 全服/全组织防守

* 圈养场需要建设投入：遮光结构、维生系统、防逃脱设施
* 圈养个体有"产量曲线"：过度榨取会导致个体衰竭死亡（精纯度衰减规则同样适用于活体资产）
* 圈养场是宗门级的核心资产，也是 PVP 与夜袭的首要目标

### 4. 道德灰度与阵营分歧

玩家是压迫者——这是题材的默认立场，不回避。宗门/组织之间因此存在**理念维度**的冲突，不只是抢地盘：

* **灭绝派**：敏化人是失控产品，应彻底清除
* **圈养派**：敏化人是资源，应最大化利用
* **温和派**：主张有限共存 / 有限利用（灰色中间态）

> 【待定·分歧点】是否开放"站在敏化人一边"的隐藏路线（第三阵营/背叛玩法）？
> 方案 A：玩家单一压迫者立场，灰度只停留在叙事层与阵营理念——实现简单，主题锋利。
> 方案 B：开放敏化人阵营或背叛路线——世界观利用率最高，但平衡与内容量成本巨大。

## 七、世界轮回：污染—失控循环

### 1. 熵债机制

每次施法，失活 CPC（消旋废物）进入环境。失活 CPC 并非惰性——它处于"半活性"状态，在环境中缓慢积累，随机催化不可控反应：天气异常、生物异变、地形劣化。

世界存在一个**背景污染度（熵债）**，随全服施法活动单调上升。

### 2. 通关条件（沿用玩法框架）

* 全图区域清空（地表游荡者与敏化人威胁清除）
* 零号实验体被讨伐

通关意味着：本纪元的敏化人威胁与污染源被**人为结算**，世界进入低活性平衡态。

### 3. 纪元结算

* **通关奖励**：绝版资源、唯一编号道具、专属称号/外观
* **旧世界**：转为永久养老服（怀旧服），数据全保留，可长期停留经营
* **新世界**：下一个生态圈/下一片待开发大陆开启，即新赛季
* **角色继承**：进入新世界只保留外观、称号、纪念道具；数值与装备全部重置（世界观解释：跨生态圈迁徙带不走物质资产，只带得走记忆与身份）
* **新人入口**：最新世界 / 中期世界（推荐开荒）/ 旧世界（养老）三选一

| 天材地宝（成长阶段资源） | **活性结晶矿床**：成核 → 生长 → 熟成；早采活性低，晚采有被他人/敏化人采走的风险 |

## 九、战斗系统映射

### 1. 三大操作流派（来自施法途径）

| 流派 | 来源 | 操作定位 |
|---|---|---|
| 手势/结印 | 掌指分泌 | 中程速射，灵活高频 |
| 咏唱/言灵 | 声带雾化 | 远程重炮，高威力，可被打断 |
| 接触渗透 | 皮肤直接接触 | 近战附魔，武器强化 |

### 2. 两条能量路线（来自两类反应）

* **毁灭系（耗蓝）**：吃环境介质，受地形与气氛制约
* **构造/治疗系（耗血+蓝）**：自残供能或依赖外置血包——圈养敏化人是这条路线的顶级后勤

### 3. 克制与反制

* 酸雾/蛋白酶气雾 → 化学沉默
* 气流/气压弹 → 吹散催化场
* 以上既是 PVP 战术，也是怪物机制（部分敏化人个体掌握反制手段）

### 4. 成长路径（无断层）

1. **新手**：地表生存 + 浅层敏化人（单人安全线）→ 基础装备
2. **成型**：组队地下探索 → 中级装备
3. **进阶**：参与区域外围/中段攻坚
4. **毕业**：核心区攻坚 + 深层讨伐 + 零号之战

## 十、社会形态与美术方向

### 1. 无政府主义社会

故事发生在高度发达但**无统一政府**的社会：旧秩序在敏化人失控事件中崩塌，城邦、飞地、工坊各自为政。

**这正是"宗门生态"的世界观地基**——没有政府，学会、工坊、氏族就是唯一的社会单位。玩家组织不是游戏系统，是世界本身。

### 2. 美术方向：高科技低秩序的生物朋克

* **质感**：玻璃管、气压表、黄铜、皮质绑带与生物组织混搭；不是干净的全息科幻
* **施法特效**：气溶胶雾化 + 电离辉光，拒绝光污染式粒子糊脸
* **玩家外观**：高度自由——这个社会的人随便设计自己的视觉形象（义体、生物装饰、服装拼贴、风格混搭）
  * 顺手服务位面继承规则：外观是最值得"带走过纪元"的资产
* **参考气质**：《灵笼》《Scorn》《赛博朋克 2077》街头层
